# ADR-001：AI 生成代码必须默认在 Docker 沙箱中执行

- 状态：待实施
- 日期：2026-07-27

## 背景

Coder 的输出是不可信代码。当前实现会在 Docker 不可用或镜像拉取失败时自动降级到
宿主机 `exec()`，生成代码因此可能访问用户文件、网络、凭据或启动子进程。

## 决策

默认只允许在受限 Docker 容器中执行生成代码。Docker 不可用时返回安全错误。

仅当操作者显式设置 `ALLOW_UNSAFE_LOCAL_EXEC=true` 时允许本地执行，并输出警告。

Docker 容器应采用：

- 禁止网络
- 只读根文件系统和只读代码挂载
- 清空 Linux capabilities，启用 `no-new-privileges`
- 非 root 用户
- CPU、内存和 PID 限额
- 受限临时文件系统
- 宿主机执行超时和自动删除

## 后果

- Docker 故障将安全失败，不会静默降低安全等级。
- Docker 不是恶意代码的绝对安全边界；未来仍需考虑独立工作节点和更严格隔离。
